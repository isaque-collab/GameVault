# Front-end do GameVault

SPA React da V1: descoberta de jogos, conta, Favoritos, Wishlist e avaliações, consumindo a API Spring Boot.

## Stack

* React 19
* TypeScript
* Vite 8
* React Router 8

## Desenvolvimento

Com o back-end em `http://localhost:8080`:

```bash
npm install
npm run dev
```

O Vite encaminha `/api` para o back-end. A aplicação fica em `http://localhost:5173`.

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

A documentação do produto, incluindo o fechamento do front-end, está no README da raiz e em `GameVault_Documentacao_Projeto_V1.3_Frontend_Concluido.docx`.
